# Frozen public-code baseline recipe

2026-10-11 user-approved operational amendment: two ranks, local batches32(UATVR)/64(CLIP4Clip), unchanged global batches64/128 and exact schedules. There is no gradient accumulation; one backward/optimizer update per global batch. Shared-card allocator cap60GiB/rank plus8GiB additional prelaunch headroom. A new matching two-rank production Q0 must pass before science. This change is registered before any scientific GPU run.

Both methods use authenticated CLIP ViT-B/32, FP32 without TF32/autocast,12 maximum frames,32 text tokens,5 epochs and seeds713/714/715. All164920 training captions are traversed exactly once per epoch. Every global batch has distinct official video identities. Each video's20 captions are shuffled within identity and traversed over shuffled identity rounds, carrying partial batches across rounds; the final batch is retained and equally partitioned across ranks. This differs from the upstream random-caption loader and prevents same-video captions being treated as negatives; official diagonal and MIL objectives remain unchanged.

UATVR: global batch64, base LR5e-5,4-layer sequential transformer initialized from CLIP's first4 text blocks, frame positions initialized from CLIP positions, word positions left at official random initialization. Extra video/text tokens2/2 and7 Gaussian samples match pinned public-code defaults. The paper's token ablation includes3/2; this public-code recipe is not represented as a parameter-exact reproduction of that row. Inference uses the upstream WTI logit; Gaussian samples are not the ranking score. Evaluation preserves RNG around upstream unused draws.

CLIP4Clip: meanP, global batch128, base LR1e-4. Normalize individual frame embeddings, mask/pool valid frames, normalize pooled video and EOS text, then use learned CLIP scale times cosine similarity. Zero padded embeddings are normalized safely before masking, with unchanged nonzero-frame semantics.

Optimizer: pinned upstream BertAdam, beta1=.9,beta2=.98,epsilon1e-6, no moment bias correction, weight decay.2 except upstream bias/LayerNorm naming exemptions, CLIP LR coefficient.001. `warmup_cosine` uses warmup.1 and the upstream cosine formula. Total steps equal the exact retained batches per epoch times5. Global gradient norm is clipped to1, followed by the upstream optimizer's per-parameter clipping; CLIP logit scale is capped at log100 after steps. The first upstream warmup step has LR0. Exact `freeze_layer_num=0,linear_patch=2d` policy freezes bottom embeddings/convolution/pre-normalization and trains all transformer blocks, final normalizations/projections and temperature.

Decoder: OpenCV RGB, floor integer FPS as upstream, one selected frame per second, then uniform index slicing to12 when longer; otherwise zero pad and retain valid mask. CLIP bicubic resize/center-crop and original normalization. Missing/failed certified frames fail the run rather than becoming zero training labels. Decoder thread count1 bounds CPU contention; actual pixels match the existing default decoder in a real video test.

Compatibility corrections are disclosed: standard autograd all-gather replaces upstream slice-only backward to give correct DDP global-gradient normalization; single-process training guards the barrier; boolean masks retain their device; unused blanket import handling is removed. Vendor original/adapted SHA-256 values and upstream commit are in `src/semantic_retrieval/full_data/upstream_uatvr/PROVENANCE.json`. Checkpoint restoration is strict and validates model, optimizer moments/order, source/recipe/input identity and rank RNG before loading.

Evaluation: all10000 validation captions × all500 validation videos, raw scores (DSL=false), canonical ties, T2V official video and V2T best-ranked relevant caption among all captions. Earliest highest validation raw T2V R@1 selects the epoch. This differs from the paper's official1k test and9k training split; no validation result is called a paper-main-table reproduction.
