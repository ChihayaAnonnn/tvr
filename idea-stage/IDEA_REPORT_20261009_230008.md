# 基于 UATVR 的创新方向：初步排序报告

日期：2026-10-09。13 个分片候选，按机制键合并一个重复后保留 12 个；0 个科学 pilot。本报告提供可证伪方向和初步查新，不是完整新颖性认证，也不是实验启动授权。所有成本均为估计。

## 阅读结论与当前仓库状态

原论文的核心是 DSA 可学习 token、词帧交互以及 DUA 的高斯采样、多实例对比和 KL 训练目标。应分别研究“匹配能否更准确”和“能否判断答案可信”，不能把表征方差直接解释为错误概率。当前仓库已重建为 `src/semantic_retrieval/`；历史 ledger 的 `modules/modeling.py` 路径并非当前实现路径。原论文也不能当作当前系统已经复现的证明。

研究记忆中，candidate-independent CSD 方差头和 SAP 失败预测属于已证伪路线；旧 A3 在 validation 的注册 gate 失败，零参数 entropy 更强。该证据仅约束已测方法，不能推出所有概率建模无用。UATVR 等方法的概率增益不能概括为已经证实的 hubness 校正，ledger E-76–83 已限制这种家族归因。

2026-10-01 重建基础链路合成四卡资格 PASS，但新增 pilot study 仍明确 `scientific_authorized: false`、`stage0_passed: false`，其新增 Q0 registry 最新记录为 reserved。不能把基础链路资格外推到新增科学链路。MSRVTT/MSVD test 继续 sealed。此次只写研究报告，没有 reserve、训练、校准或读取 test。

## 文献版图与差异边界

- [UATVR](https://arxiv.org/abs/2301.06309)：多粒度 token 和概率训练，是方法起点。
- [T-MASS](https://arxiv.org/abs/2403.17998)、[ProTA](https://arxiv.org/abs/2404.12216)：随机文本、概率 token 与内容不对称已有人研究。仅换一个分布不足以说明贡献。
- [TokenBinder](https://arxiv.org/abs/2409.19865)：联合比较多个候选并重排；候选上下文交互不是空白。
- [VideoComp](https://openaccess.thecvf.com/content/CVPR2025/papers/Kim_VideoComp_Advancing_Fine-Grained_Compositional_and_Temporal_Alignment_in_Video-Text_Models_CVPR_2025_paper.pdf)：组合与时间对齐；[MSC PRVR](https://arxiv.org/abs/2510.27432)：保持语义关系及连续片段。时序头或分段本身需要额外差异。
- [Holmes](https://arxiv.org/abs/2605.06083)：分数证据、软标签及 dustbin OT；“加 EDL/OT”并非充分差异。
- [Moment of Untruth](https://arxiv.org/abs/2502.08544)：负查询拒绝已进入视频定位任务；不能声称首次视频拒答。
- [AdaVid](https://www.openaccess.thecvf.com/content/CVPR2025W/EDGE/papers/Patel_AdaVid_Adaptive_Video-Language_Pretraining_CVPRW_2025_paper.pdf)、[VideoRAG](https://arxiv.org/abs/2501.05874)：自适应视频计算和帧选择是近邻。
- [BLiM](https://arxiv.org/abs/2507.23284)：候选先验归一化；[TARA](https://www.robots.ox.ac.uk/~vgg/research/tara/)：文本训练的细微语义检索，要求对简单硬负例训练做强对照。

检索覆盖了概率表示、假负例、时序组合、拒答、候选校准、计算分配及蒸馏等多种查询。以上含摘要、项目方法说明和部分全文阅读；未完成逐候选的穷尽查新，不给虚假的新颖性分数。

## 优先候选（综合排序：主方法与动作决策优先，语义审计并行）

### 1. 同一事件约束的 WTI：避免局部高分拼出错误答案

**实际做法：** 保留词帧相似度；给描述同一事件的词建立共享的事件窗口；在窗口内部评价整体支持，再用最佳完整事件支持给视频排序。先做无训练诊断，有信号后才考虑轻量匹配器。

例如查询“红衣男子踢球”，候选可能分别出现红衣观众和另一个踢球的人。独立词帧最大值可能同时很高，却没有完整事件。该例只是待验证的机制假设。仅把帧限制在同一窗口也未必解决同帧不同人物的绑定，不能夸称完成对象级推理。

**假设：** 某部分错误由独立局部匹配缺少联合事件约束造成。**最低验证：** 约 200 组独立 validation、人工核验的事件绑定对，控制词汇、帧数、窗口搜索次数及时间长度；比较原 WTI、普通窗口最大值、随机窗口和联合事件约束。**判据：** 在未参与选择的验证部分，绑定冲突区分率和排序改善，且普通查询退化在预先约定范围内；按来源视频簇估计置信区间。收益若由额外搜索或短窗口解释，则机制不成立。

**近邻与增量：** VideoComp/MSC/Holmes 很近；目标应是“同局部元素、不同事件绑定”的受控证据与联合支持机制，不能仅称时序建模。**风险：MEDIUM–HIGH；贡献：诊断+方法。** 缓存齐备时约 1–3 CPU 小时，审核 6–10 人时；新增编码另估。实现约 1–2 周。未跑 pilot。

### 2. 扩候选还是补帧：让不确定性决定下一次取证

**实际做法：** 从小候选集、少量帧开始；分别测扩大候选与对当前视频补帧能挽救哪些查询；先估计 oracle 上限，再用初始可观测信息学习简单动作规则，动作含停止。

**假设：** 漏召回与视觉证据不足对应不同补救动作。**最低验证：** 约 200 个独立 validation 查询，在等真实预算下比较固定扩库、固定补帧和两动作 oracle；oracle 仅为离线分析，不使用 GT 在线决策。只有 oracle 有明显余量才训练规则。**判据：** 动作互补且初始状态能预测收益，学习策略在独立验证胜过最佳固定策略；oracle 有余量而策略无收益也是重要负结果。

**近邻与增量：** 现有 semantic-answerability pilot 已有存在头与有限扩检，AdaVid/VideoRAG 已有自适应计算。新贡献必须是两种取证动作的可预测互补性，不能把扩检本身重报。**风险：MEDIUM；贡献：方法+系统。** 缓存齐备 CPU 1–3 小时；补帧编码粗估 1–2 GPU 小时，须先测吞吐并计解码、编码、重评分和 I/O。实现约 1–2 周。未跑 pilot。

### 3. 区分多答案与模型失败：语义多解风险审计

**实际做法：** 在有限验证库独立审核每条查询的相关视频集合；冻结同一个检索器与预测；分别按官方配对和语义相关集合评价 entropy、margin 及风险曲线。

**假设：** 多个正确答案可能导致较小 margin、高 entropy，却不意味着 top-1 错误。**最低验证：** 100 条查询×20 个候选，双人审核及仲裁；先按来源组件划分开发与独立验证，候选构造写清。**判据：** 标签空间改变实际误差、风险曲线或方法排序，并在审核一致性和抽样误差下仍成立。没有改变则否定此诊断假设。

**近邻与增量：** 属于现有 benchmark_annotation pilot 的独立语义扩展，与 Holmes/负查询检索接近。不是新造一个存在头，而是检验评价对象是否混淆。有限库无答案只能声明该有限库无答案；未配对标签不是语义负例。**风险：MEDIUM；贡献：诊断+benchmark。** 缓存齐备 CPU <1 小时，约 15–30 人时审核。未跑 pilot。

## 新上下文评审原文

建议优先以下三项，其余九项保留；这是初步排序，不是穷尽新颖性认证。

1. **同事件一致性 WTI（CAUTION，主方法线）**：让各查询成分的匹配共享事件归属，抑制独立最大值拼接不同事件。最近邻 MSC、VideoComp 已涉及关系与时序，增量必须落在“相同局部证据、不同共同事件归属”的区分能力。最强反对：只是已有连续片段匹配的改写。廉价证伪：保持局部内容、改变事件组合；若基础 WTI 已能区分，或简单窗口约束已解决问题，复杂模块价值不足。

2. **语义多正例审计（PROCEED，先取证）**：独立复核高分官方负例，检验所谓不确定性是否主要来自漏标正例，再决定是否训练多正例排序。与现有 pilot 的区别是新增人工语义证据；最强反对是收益仅来自通用标签修正。廉价证伪：盲审匹配难度的小样本；若歧义比例低，或与目标错误无关联，则不扩展。

3. **扩候选还是补帧（CAUTION，决策线）**：按单位成本的预期错误下降选择扩库、补帧或停止。最近邻为 AdaVid 与现有扩候选 pilot，增量是联合决定获取哪类证据。最强反对：固定策略足够。廉价证伪：先计算动作 oracle；若相同成本下相对最佳固定策略无明显空间，就不训练策略。

不要用 DUA 的原始 σ 直接支撑上述决策；概率正则作用应另做匹配预算诊断。

综合排序把动作决策列为方法备选第二，评审按先取证价值把语义审计列第二；二者同属前三，没有删除剩余候选。
