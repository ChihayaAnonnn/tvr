## 在追的问题

① |Rel| 轴——全局阈值 83.3%(=1) → 98.3%(6+)，spread 15.0 pt，oracle 压到 0.7；
② 难度轴——把 |Rel| 钉死在 1，按难度五分位仍是 96.2% → 83.1%，**13.1 pt**，
随机分位地板只有 0.6，而 oracle |Rel| 分层对它毫无作用。
**oracle 不是天花板，只是一个轴上的天花板**；以前所有「还剩 13 pt」都只算了一个轴。

## 上一步结论（step-002，符号翻转验证）
主判据 4/4 run × 3/3 特征全过：同一个特征在层内和层间要求**相反符号**的 λ 响应
（熵 +0.59 对 −2.26；gap1-100 −0.88 对 +4.11），换算成每 SD 的 λ 位移是同量级
反方向。**合并拟合一个单调 λ(x) 在数学上就做不到**，CQR 的 2.5 pt 是模型形式的
天花板不是特征的。gap1-100 / top1 z 上更糟：合并回归学到层内斜率、用到层间时
方向是错的。→ 「歧义进分组、难度进分数、δ 在组内单独拟合」这个设计有直接依据了。
