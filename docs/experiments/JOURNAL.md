# 实验流水账 (append-only)

一步一条，**跑之前先写**，跑完追加结论。只追加，不改写历史条目
（除了把 `status:` 从 RUNNING 翻成 DONE/ABANDONED，以及补 `结论:`/`下一步:`）。

叙事和论证归 `baseline-gap-diagnosis.md`；当前状态归 `STATUS.md`；
这里只记"第 N 步做了什么、期望什么、实际什么"。

## 条目格式

`status:` / `run_dir:` / `完成信号:` / `证伪条件:` 是**机器字段**，hook 靠它们判断，
必须顶格以 `- <键>:` 开头。其余字段给人看。

```markdown
## [YYYY-MM-DD HH:MM] step-NNN 一句话标题
- status: RUNNING
- run_dir: ckpts/xxx          # 没有产出目录就写 -
- 完成信号: ckpts/xxx/final_test.json   # 哪个文件出现就算跑完
- 假设: 一句话，可证伪的那种
- 证伪条件: 看到什么就算这个假设死了（**必须在跑之前写**）
- 命令: 复现用的那一行
```

时间戳用 `date '+%Y-%m-%d %H:%M'` 取。SessionStart 注入里也带了当前时间，
别凭印象填——模型没有时钟。

`完成信号:` 省略时默认 `<run_dir>/final_test.json`，所以训练类不用写。**离线分析
必须写**（`.scratch/xxx.npz` 之类），否则 Stop hook 认不出它跑完了。`run_dir` 是 `-`
且没写完成信号的条目，只能靠人手动收尾。

`证伪条件:` 不是给人看的散文，是 hook 会检查存在性的字段：写了空值等于没写，
PostToolUse 和 SessionStart 都会揪出来。

跑完在同一条目下追加：

```markdown
- status: DONE
- 结果: 数字，带单位和对照
- 结论: 假设成立/不成立，为什么
- 下一步: 或者写"无，回 STATUS.md 重新定向"
```

`status:` 的取值只有三个：`RUNNING` / `DONE` / `ABANDONED`。
同一条目里 `status:` 出现多次时以**最后一次**为准，所以翻状态就是再追加一行。

## [2026-07-31 13:39] step-001 用条件分位数回归取代「预测 |Rel| 再分桶」
- status: RUNNING
- run_dir: -
- 完成信号: .scratch/cqr_probe.txt
- 假设: 上一步的负结果指向的是**目标函数错了**，不是特征不够。我们一直在预测
  |Rel|（有多少视频相关），再按预测值切 5 个桶、每桶一个阈值。但加 σ 让 ρ 从

  P(margin ≤ λ(x) | x) = 1−α。CQR（Romano/Patterson/Candès 2019）直接估这个：
  先在校准集上做分位数回归，再对残差做一次 conformal 修正，保留有限样本边际保证。
  它连续、不分桶，也完全不需要 |Rel| 标注。
  同时把特征从 4 个标量扩到 ~15 个**看得见 gallery 的**统计量（softmax 熵、
  rank 10/50/100 处的分数、top1 到各 rank 的落差、行均值方差等）——|Rel| 本质上
  是查询相对于这 1000 个视频的性质，只看 top1/top2 是看不到的。

  13.3 / parity_a4 13.0 / hygiene_a0 14.8 / hygiene_a4 14.8 pt），配对 Δspread
  在 4 个 run 里达不到 3 个 ≤ −2.0 pt，就算这个假设死了：免费的检索分数统计量
  已经榨干，只剩「文本编码器在 |Rel| 上 fine-tune」这一条路。
  附带：若 spread 降了但平均集合大小涨过 1.5 倍，也算没通过——那是用更大的集合
  换来的均匀，不是信息。
- 命令: python scripts/conditional_conformal_probe.py --run ... | tee .scratch/cqr_probe.txt

## [2026-07-31 17:15] step-002 层内/层间斜率是否符号相反（两路信号设计的前提）
- status: RUNNING
- run_dir: -
- 完成信号: .scratch/within_between.txt
- 假设: 上一步测到一个压制（suppression）迹象：熵(T=0.25) 跟 conformal score σ 的
  Spearman 在全集上只有 +0.29~0.36，在 |Rel|=1 的 363 个查询**内部**反而升到 +0.476。
  层内相关度高于合并相关度，只有当层内效应和层间效应方向相反、合并时互相抵消才会
  出现。机制上说得通：层间「熵高 → 相似视频多 → |Rel| 大 → 需要的 λ 小」，层内
  |Rel| 固定「熵高 → 这个查询确实难 → σ 大 → 需要的 λ 大」。若成立，**任何单调的
  λ(x) 都同时满足不了两者**，这就是 CQR 加 17 个特征只买到 2.5 pt 的机制原因——
  不是特征不够，是模型形式错了。它同时是「歧义进分组、难度进分数、层内单独拟合」
  这个设计的唯一依据。
  Part B 是同一件事的另一面：如果 |Rel| 固定住之后层内还有可利用的难度异质性，那么
  在 |Rel|=1 层**内部**、用单一阈值时，按（样本外预测的）难度分位切开的覆盖率应该
  散得开；散不开就说明层内没活干，两路信号退化成一路。
- 证伪条件（**跑之前写**）:
  Part A 主判据——对 `entropy T=0.25` / `gap 1-100` / `top1 z` 这三个携带层内信号的
  特征，在 τ=0.9 的分位数回归下 sign(β_within) ≠ sign(β_between)，必须在 ≥3/4 个 run
  上、对 ≥2/3 个特征成立，且 β_within 的 bootstrap 95% CI 不跨 0。不成立就是假设死，
  「层内单独拟合 δ」的设计没有依据，机制要重想。
  Part A 附带判据（衰减）——同样的 run/特征上要有 |β_pool| < 0.5·|β_within|。符号相反
  但 pooled 没被衰减，说明两个效应不在一个量级，「抵消」的说法不成立。
  Part B 判据——|Rel|=1 层内、单一阈值下，按难度五分位的覆盖率 spread（配对 bootstrap，
  先平均五列再相减）必须比**随机五分位**的同一读数至少高 5.0 pt，在 ≥3/4 个 run 上。
  达不到就说明层内异质性淹没在 36 个查询/格的噪声里，δ 头不值得做。
- 命令: python scripts/within_between_probe.py --fire .scratch/mm-retrieval-evaluation/data/fire_msrvtt_dataset.json --test-csv /data2/hxj/data/MSRVTT/csv/MSRVTT_JSFUSION_test.csv --run parity_a0=... --run parity_a4=... --run hygiene_a0=... --run hygiene_a4=... | tee .scratch/within_between.txt
- status: DONE
- 结果:
  **Part A（符号）**：`flip` 列 **4/4 个 run × 3/3 个特征全是 yes**（该列已内含
  β_within 的 bootstrap 95% CI 不跨 0 这一条）。parity_a0 为例：
  熵 β_within **+0.592** / β_between **−2.261**；gap1-100 −0.880 / +4.109；
  top1 z −0.822 / +3.784。每层的 β 单独看也基本同号（熵：+0.75 +0.03 +1.02 +0.93
  +0.39），不是被某一层带偏的。四个 run 的数值稳定。
  两个斜率的方差尺度不同（sd(x̄_s)/sd_within = 0.55 / 0.30 / 0.33），换算成
  「每 1 个相应 SD 的 λ 位移」才可比：熵 层间 −1.09 对层内 +0.52，gap1-100
  +1.16 对 −0.84，top1 z +1.18 对 −0.77。**同量级、反方向。**
  **Part A 附带判据（衰减）只有熵过**（3/4 run：β_pool −0.07/−0.18/+0.12/+0.05

  **Part B（层内异质性）**：|Rel|=1 的 363 个查询内部，单一阈值下按样本外难度五分位

  三条：

  (2) **发现了第二个 13 pt 的条件覆盖缺口，跟第一个正交。** oracle |Rel| 分层把

  (3) **层内 CQR 同样是用集合大小换均匀**（4 倍，比全局那次的 1.5 倍还差）。363 个
  查询里 90 行拟合 17 列，分位数回归过拟合、conformal 修正只能靠放大集合来兜底。
  δ 头要能用，要么特征少得多，要么信号强得多（外部判官），不能照搬这个配方。
- 下一步: 机制依据齐了，缺的是能真正闭合的信号。按 STATUS 的两条走：先把校准层换成

## [2026-07-31 17:44] step-003 差距在校准层还是信号层——GCC 条件 conformal
- status: RUNNING
- run_dir: -
- 完成信号: .scratch/gcc_probe.txt
- 假设: step-002 证明了两件事：条件覆盖有**两个正交的轴**（|Rel| 13–15 pt、层内难度
  13.1 pt），且同一特征在两个轴上要求**相反符号**的 λ 响应。Mondrian 分桶只管第一个
  轴，CQR 合并拟合两个轴都管不好。Gibbs–Cherian–Candès（arXiv 2305.12616，号待核）
  的条件 conformal 正好是对着这个结构的工具：给定一个有限维函数类
  F = span{φ_1..φ_d}，在 τ=1−α 上做 φ 的**分位数回归**，其一阶条件恰好是
  E[φ(X)(1{S≤λ(X)} − (1−α))] = 0 ——也就是对 F 里每个方向都成立的条件覆盖。
  于是把两个轴写进 F 就行：φ = [分桶指示 1{b(x)=k}]_{k=0..4} ⊕ [1{b(x)=k}·d(x)]，
  其中 b 是预测 |Rel| 的五分桶（轴一），d 是桶内中心化的难度标量（轴二），
  **交互项正是 step-002 的符号翻转要求的**——每个桶的 d 斜率可以不同号。
  d 只用一个标量，遵守 step-002 「δ 头限特征数」的约束（层内 CQR 用 17 个特征时
  集合涨 4 倍）。
  这一步真正要问的不是「能不能赢」，是**差距在校准层还是信号层**。
- 证伪条件（**跑之前写**）:
  主判据——`GCC +inter` 相对 `bucket rich` 的配对 Δ 必须同时满足
  Δspread_rel ≤ −2.0 pt **且** Δspread_diff ≤ −4.0 pt，在 ≥3/4 个 run 上，
  且平均集合大小不超过 1.5 倍。（两个轴的门槛不对称是故意的：轴一已经被打了很久，
  轴二至今没有任何方法碰过，有 13 pt 空头寸，校准层若是主因就该掉得更多。）
  **诊断判据（这才是这步的目的，独立于主判据）**——看 `GCC +inter` 的 spread_rel
  绝对值：≤5.0 pt 判**差距在校准层**，继续走这条线；>8.0 pt 判**差距在信号层**，
  校准层已经做到头，直接启动外部判官（VLM 估 |Rel|）。5–8 pt 之间算没定论，
  按集合大小和轴二的结果决定。
  正确性判据——`GCC buckets`（F 只有分桶指示）在数学上等价于 Mondrian，
  必须跟 `bucket rich` 的 spread_rel 落在 1 pt 以内，否则是 LP 实现错了，
  上面所有读数作废。

  的难度标量，sprd_dif 从 14.0 掉到 3.2–5.1 pt，只花 1.2 倍集合，全部用免费特征。
  oracle 2-axis 才 2.5–3.1，所以剩余空间很小。step-002 那 13 pt 的第二个缺口
  **一步就补上了大部分**。
  (2) **轴一（歧义）是信号层问题，校准层已经做到头。** 所有校准变体都卡在
  11.4–14.6 pt，oracle 只要 0.4–0.8。函数类换成什么形状都没用——F 里的方向再多，
  也不能凭空造出 b(x) 里没有的 |Rel| 信息。**这就是启动外部判官的证据，而且是
  「校准层已穷尽」这种有说服力的证据，不是「我们想试试 VLM」。**
