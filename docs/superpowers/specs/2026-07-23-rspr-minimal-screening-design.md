# RSPR 极简筛选实验设计

**状态：** 已获用户确认，待更新活动实验文档
**日期：** 2026-07-23

## 1. 目标

当前 RSPR Stage 1 要求 A0–A8 每项至少运行三个随机 seed，名义上需要
27 个四卡、五 epoch 作业。该安排把早期机制筛选与最终统计复现混为一体，
且 A3 与 A6 在默认 `RSPR_MATCH_MODE=soft` 下配置等价。

本设计把 Stage 1 改为两级门控：

1. 用一个 seed 完成最小因果筛选；
2. 只有核心方法通过预设门槛时，才对基线、容量控制和胜出方法补齐三个 seed。

目标是在不牺牲关键因果对照的前提下，将当前阶段的完整作业预算从至少 27 个
压缩到最多 12 个。若首轮没有明确收益，则在 6 个作业后停止。

## 2. 固定实验条件

所有作业继续共享当前 RSPR Stage 1 的固定条件：

- OpenAI CLIP `ViT-B/16` 相同权重起点；
- MSR-VTT trusted-v1 seed 0 数据划分；
- 相同代码 commit、数据协议 manifest 和 TQFS 配置；
- `FREEZE_LAYER_NUM=8`；
- 四卡、global forward batch 256、gradient accumulation 1；
- 单一连续五 epoch optimizer schedule；
- CLIP blocks 8–11、DSA、WTI 与活动 RSPR 分支从第一步联合训练；
- internal-val 指标用于筛选，所有成本和数值诊断按现有记录表采集。

数据划分 seed 固定为 0；本设计中的训练随机 seed 取 0、1、2，两者不得混淆。

## 3. 第一轮：单 seed 因果筛选

第一轮只使用训练随机 seed 0，共运行六个作业：

| 实验 | 配置 | 保留原因 |
| --- | --- | --- |
| A0 | `rspr_mode=off` | 确定性 DSA/WTI 基线 |
| A1 | `rspr_mode=mean, K=1, top_r=0` | 概率头参数量与均值表示控制 |
| A2 | `rspr_mode=stochastic, detach_samples=true` | 随机增强但无重参数化梯度的控制 |
| A3 | `rspr_mode=stochastic` | 完整 RSPR |
| A7 | A3 去掉 stochastic rank loss | 判断随机排序监督是否必要 |
| A8 | A3 去掉 anchor KL | 判断方差约束是否必要 |

本轮不运行：

- A6：当前默认配置与 A3 等价，不产生独立证据；
- A4 legacy：仅在核心结果成立且需要旧 UATVR 横向解释时补充；
- A5 hard-max：仅在核心结果成立且需要 matcher 选择解释时补充。

已有 A3 GPU smoke 只证明运行链路可达，不是完整 seed 0 结果，不计入六个作业。

## 4. 第一轮门槛与胜出规则

### 4.1 有效性门槛

任一作业触发下列条件时，不进入统计比较，先修复实现：

- 任意 loss 出现 NaN 或 Inf；
- `logvar` 连续一个 epoch 全维停在 -8 或 2；
- A3 对 DSA、mean 或 logvar 没有有限梯度；
- 固定推理噪声重复评估产生不一致排名。

### 4.2 核心方法晋级门槛

A3 只有同时满足以下条件，第二轮才解锁：

1. internal-val T2V R@1 至少比 `max(A0 T2V R@1, A1 T2V R@1)` 高
   0.5 个百分点；
2. internal-val V2T R@1 相比 `max(A0 V2T R@1, A1 V2T R@1)` 下降
   不超过 0.5 个百分点；
3. 数值稳定性没有触发停止条件，且没有 OOM；峰值显存与吞吐完整记录。

这里的 0.5 个百分点是早期筛选的最小实际效应门槛，不解释为统计显著性。
若 A3 未通过，则停止 RSPR 多 seed 扩展，不用重复实验追逐单次波动。

### 4.3 因果解释与最简胜出配置

- A3 相比 A2 的 T2V R@1 增益不足 0.5 个百分点时，不宣称重参数化梯度有效；
- A7 或 A8 的 T2V R@1 距离 A3 不超过 0.5 个百分点，且相对
  `max(A0 V2T R@1, A1 V2T R@1)` 满足相同 V2T 退化限制与数值稳定性时，
  优先选择去掉对应辅助项的更简单配置；
- 若 A7、A8 都符合简化条件，先选择 T2V R@1 更高者；T2V R@1 相同时，
  选择 V2T R@1 更高者；
- 若 A7、A8 都不符合简化条件，胜出配置为 A3。

A2、A7、A8 的单 seed 结果只用于门控与机制筛选；未经第二轮复现，不形成
跨 seed 稳定性的论文主张。

## 5. 第二轮：只复现三个配置

只有 A3 通过核心方法晋级门槛时，才运行第二轮。对以下三个配置分别增加训练
随机 seed 1 和 2：

1. A0 确定性基线；
2. A1 mean-only 容量控制；
3. 第一轮选出的最简 RSPR 胜出配置。

第二轮新增 `3 × 2 = 6` 个作业。连同第一轮，当前 Stage 1 最多运行 12 个
完整作业。最终报告每个配置 seed 0、1、2 的逐 seed 结果以及均值和标准差，
不只报告最优 seed。

若三 seed 结果不能保持胜出配置相对 A0 和 A1 的方向一致，则结论记为不稳定，
不继续增加 RSPR 复杂度。

## 6. 延后实验与后续门槛

A4、A5 不属于当前 12 作业预算。只有三 seed 核心结果成立，且论文解释确实
需要 legacy 或 hard-max 对照时，才允许各补一个 seed 0 作业。

A9 Beta evidence、A10 采样数扫描和 A11 采样策略比较继续冻结。不得在当前
两轮完成前实现或启动 Beta evidence。

DiDeMo 数据协议与第二数据集实验继续延后。只有 MSR-VTT 三 seed 结果通过后，
才创建独立计划；不得用临时 loader 拼接扩大当前实验范围。
