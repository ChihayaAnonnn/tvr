# GeoFlowVLM 精读与理论边界

GeoFlowVLM 的价值是把条件匹配分布和每个模态的数据分布支持度分开讨论。
我的判断是：它为概率解释提供了比单个方差头更清晰的结构，
但候选熵、密度代理量与真实检索风险之间仍有未解决的环节。
阅读 v2，版本与来源见 [SOURCE](SOURCE.txt)；没有复现模型。

## 方法的事实依据

[原文 §3–4](https://arxiv.org/html/2605.13352v2#S3)在冻结的归一化图文嵌入上，
用一个 masked Riemannian flow 学联合与两个条件模式。
条件样本经 gallery 上的核聚合得到离散熵；边缘负对数密度和作为 density-based epistemic score。
作者明确没有编码器参数的 Bayesian posterior。

核心关系（论文 Eq.1、3–7 与附录 C.5）：

\[
z=(e_I,e_T)\in\mathbb S^{d-1}\times\mathbb S^{d-1},\qquad
L=\mathbb E\|m\odot(v_\phi-v_{\mathrm{target}})\|_g^2,
\]
\[
\hat e^{(r)}\sim p_\phi(\cdot\mid q),\quad
w_j=\frac1M\sum_{r=1}^M\exp(\kappa g_j^\top\hat e^{(r)}),\quad
\pi_j=w_j/\sum_k w_k,\quad H=-\sum_j\pi_j\log\pi_j,
\]
\[
-\log p_\phi(e_I,e_T)=
[-\log p_\phi(e_I)-\log p_\phi(e_T)]-\mathrm{PMI}_\phi(e_I,e_T),
\]
\[
u_{\mathrm{ep}}=-\log p_\phi(e_I)-\log p_\phi(e_T).
\]

[§5](https://arxiv.org/html/2605.13352v2#S5)分别用检索分箱相关性评价 H、
用零样本分类 selective accuracy 评价 u_ep。
Table 2 的 COCO I→T 分箱 Spearman 为 -0.981；作者不声称在 epistemic 任务上数值胜过 REPVLM。
这些是作者报告值，不能视为本仓库的视频检索复现。

## 联合分布为何比模态独立方差更清楚

**我的分析：** 在理想准确模型中，条件分布回答“给定这个查询，哪些目标可能成立”，
边缘分布回答“这个模态的表示在代理训练分布中常见吗”。
二者能给出不同结论：常见的“有人走路”可能对应许多目标；罕见但描述具体的查询可能只对应一个目标。

在单位球面上，一个 ambient Gaussian 方差也可能包含径向变化；
归一化之后这些变化不会全部成为排序变化。
在切空间学习并沿球面积分，至少让分布的支持空间与实际余弦表示一致。
但流形正确不等于语义正确，后者仍取决于编码器和代理数据。

定理的逻辑是：mask 把联合任务和两个条件任务分成不同回归目标，
无限容量、总体最优时可分别达到目标速度场。
**我的判断：** 这解释了设计的可行性，不保证有限网络三个输出严格满足 Bayes 一致性，
也不给新查询上的校准误差界。

另一个待核对的理论条件是 OT source–target coupling 是否保留条件任务所需的起点分布。
如果 source 和 target 经联合匹配后，生成块的 source 与干净 conditioner 相关，
需要证明其条件起点仍为目标 p0；不能只凭 source 的总体边缘正确就断言成立。
这是对证明假设与训练耦合的检查问题，本次没有作者实现可用于裁决。

## Fano 下界的含义

原文 Eq.4 为

\[
H(\pi)\le h_2(r)+r\log(N-1),\qquad r=1-\max_j\pi_j.
\]

**我的推导：** 反演给出 r 的下界。即使 π 完全真实，它也不能证明接受查询的错误率
小于某个 α，因为保证低错误率需要上界或有效校准。
论文 π 还是模型样本经核与 gallery 归一化的分布，与真实标签后验之间有额外误差。

理论 predictor 是 `argmax π`。实际冻结 CLIP 的余弦 top-1 未必等于它。
MAP 的下界可以限制最优分类风险，却不能直接成为实际检索器的精确失败概率。

熵也不能严格保序 0/1 风险。例如

\[
\pi_A=(0.6,0.4,0),\quad \pi_B=(0.65,0.175,0.175).
\]

A 的 H≈0.673、r=0.4；B 的 H≈0.890、r=0.35。
B 熵更高而 MAP 风险更低。这里检验的是确定性数学命题，不是模型实验。
因此“熵是有用风险排序量”需要经验支持，不能作为无条件定理。

## Gallery 熵和语义歧义的区别

**我的推导：** 将 gallery 中每个条目复制 L 次，假定复制条目的核分数相同，
则原概率 π_j 分裂成 L 个 π_j/L。直接计算得到

\[
H_{\mathrm{dup}}=H+\log L.
\]

对多正例的语义检索，这没有增加任何新语义，也未必增加“找不到相关目标”的风险，
但条目熵上升。仅除以 log N 也不严格修复：
`(H+log L)/(log N+log L)` 会随复制数变化。

这说明离散条目 ID 的不确定性和语义相关性的多解性是不同的评价对象。
有许多正确候选时，强迫唯一 ID 分类可能制造伪错误；去掉某个正例后的失误也不能自动归为 AU。

另外 π 总会归一化为 1。如果正确目标根本不在 gallery，所有核值可以都很低，
却仍得到一个尖锐的相对分布。单独的 H 不能保证识别“无答案”。
查询在代理分布中常见也不等于当前候选集中有答案，所以边缘密度不自动补上这一能力。

## Density score 与匹配风险

**我的分析：** 论文的 epistemic 是 learned-density support 的代理；
它既不测编码器参数 posterior，也不量化密度估计器自身的认知不确定性。
把它和 Bayesian parameter uncertainty 相加并命名“总不确定性”没有自动成立的分解依据。

对固定文本 q 的候选打分，

\[
u_{\mathrm{ep}}(q,v)=\underbrace{-\log p(q)}_{\text{候选间常数}}-
\log p(v).
\]

因此候选间差异来自模态先验，而不是 q–v 交互。
这可以用于发现罕见候选或不同来源分布，但若把它直接用来重排，
还可能引入 candidate-only bias，不能直接等同于匹配失败概率。
联合 density 的优势主要应从条件分布、共同训练的边缘质量与信息增量讨论。

## 实验和复现边界

**我的判断：** 分箱 Spearman 和线性 R²说明错误更集中于高不确定性组。
把十个分箱排列得很好，与给每个查询准确的错误概率是两种要求。
良好单调性也不能替代 query-level AUROC/AURC 或带有效校准的风险结论。

主文检索 H 与分类 u_ep 的两组实验不能合并成“两个量已经共同改善视频检索可靠性”。
代理图文数据带来的知识、模型容量、计算和候选分布都可能决定迁移效果。
作者对 SigLIP 的附录也显示 density 代理量并非在每种表示几何下都稳健。

**发现的文本矛盾：** 附录 B.1 Eq.9 定义

\[
\tilde v=v_{\mathrm{cond}}+\lambda(v_{\mathrm{cond}}-v_{\mathrm{uncond}}).
\]

代入 λ=0 得到 conditional field；附录 D.4 却把 λ=0 解释为 unconditional flow。
还可能是实际消融使用另一种 scale convention。本次未核验公开实现，
所以只能记录公式与文字不一致，不能断言实验做错。
guided field 通常也不再直接对应未 guidance 的原始条件分布；总体一致性定理不能自动迁移给它。

## 对当前研究最有价值的问题

以下是我的研究判断，尚未证明新颖性，也不是执行计划：

- 如何定义对语义等价候选复制稳健的不确定性，避免把多个正确答案当作错误？
- 如何保留绝对匹配支持度，识别“无答案”，再决定返回集合、澄清或拒答？
- 在控制冻结检索分数后，条件分布、代理 typicality 或参数 posterior 各自新增了什么信息？
- 在相近预算下，生成式读出是否值得其采样与 density ODE 成本？
