# Holmes 精读与实现核对

Holmes 值得借鉴的是如何用候选之间的歧义和视频内部的对齐改变训练监督。
我的判断是：论文的检索收益有依据，但还不足以把其查询分类器当成部署时的风险诊断器。
以下区分原文事实、实现事实和我的推导。阅读版本及代码 commit 见 [SOURCE](SOURCE.txt)。

## 方法的事实依据

[论文 §3](https://arxiv.org/html/2605.06083v1#S3)针对部分相关视频检索。
帧与片段分支各取最大余弦分数，最终用加权分数排序。
训练将候选分数变为 Dirichlet 参数，以证据强度、真标签一致性、期望熵识别查询；
多义查询使用软标签。视频内用带 dustbin 的 OT 提供稠密监督。
原文总目标为基础检索损失加 inter/intra evidential loss，采用 warm-up 后联合训练。

核心定义（论文 Eq.3–9、15、17）：

\[
e_j=\exp(\tanh(s_j/\tau)),\quad a_j=1+e_j,\quad A=\sum_j a_j,
\]
\[
u=K/A,\quad c=\max(0,s^\top y),\quad
\xi=\sum_j\frac{a_j}{A}\bigl[\psi(A+1)-\psi(a_j+1)\bigr],
\]
\[
\hat y=(1-\gamma)y+\frac\gamma2(\operatorname{softmax}s^f+\operatorname{softmax}s^c)
\quad\text{仅用于多义查询},
\]
\[
L_U=\sum_j(\hat y_j-a_j/A)^2+
\sum_j\frac{a_j(A-a_j)}{A^2(A+1)}.
\]

[Table 3](https://arxiv.org/html/2605.06083v1#S4)中，ActivityNet 的完整模型 R@1 为 9.3，
去掉校准为 8.8、去掉 intra loss 为 8.7。
这些是作者报告值，不是本仓库复现。

## 相似度到证据的梯度路径

**我的分析：** `similarity → evidence → L_U → retriever` 是可微路径，
因此即使 evidence 是分数的确定性变换，辅助目标仍可以改变表示与未来分数。
这和冻结模型上再加工同一组分数是两种不同作用。

固定完整分数向量 s 后，u 和 ξ 都是 s 的函数，没有增加新观测。
这不能推出训练无用；只能推出“相同冻结分数下，新信号来自另一个独立信息源”
不应由这个变换本身来证明。

L_U 的第二项是 Dirichlet 方差和，第一项同时依赖总强度与类间相对证据。
它会改变匹配分数的优化压力。把收益归为“训练正则化、标签软化、稠密对齐”
比仅凭分布名称归为“获得独立的认知不确定性”更容易检验。

## 论文公式和实现的差异

**已核对的实现事实：** 作者公开代码
[loss.py 第 50–57 行](https://github.com/lijun2005/ICML26-Holmes/blob/73bbbfcfca241418507a9a46691f0cb834e31d8b/src/Losses/loss.py#L50)
使用

\[
e_j^{\mathrm{code}}=\exp(\tanh(s_j)/\tau).
\]

`multisrc/Losses/loss.py` 使用同一表达式；不是只在一个分支发现的差异。
软标签的 softmax 在代码中 detach；[pair_division](https://github.com/lijun2005/ICML26-Holmes/blob/73bbbfcfca241418507a9a46691f0cb834e31d8b/src/Losses/loss.py#L335)
的熵中位数取自整个 batch，论文 Eq.12 则取自初始精确集合。

**我的数值推导：** 保持 τ=0.1、s=0.5，论文表达式给出约 2.718，代码表达式给出约 101.613。
这个比较只是在相同参数下的数学计算，不是运行作者模型。

按论文表达式，始终有

\[
e^{-1}<e_j<e,\qquad
\frac1{1+e}<u<\frac1{1+e^{-1}},
\]

即 u 被限制在约 (0.269, 0.731)。单支预测概率的最大可能值还满足

\[
\max_j\frac{a_j}{A}\le
\frac{1+e}{(1+e)+(K-1)(1+e^{-1})}.
\]

因此候选数较大时，单支分布难以形成强集中。附录 B.2 的反例允许某个 e_j 无限增大、
其余为零；它解释了一般 EDL 中低 vacuity 不保证正确，但不处于论文 Eq.3 的可达范围。
这不推翻那个一般结论，却使证明与具体参数化之间存在需要说明的差距。

代码映射仍有界，但尺度完全不同。对余弦分数 s∈[-1,1]，其 u 下界是
`1/(1+exp(tanh(1)/τ))`；τ=0.1 时约 0.000492。
**不要依据论文公式的窄范围，直接宣称代码里的不确定性必然塌缩。**
这更可能是公式或实现版本差异；作者尚未在本次核对中澄清。

## 训练查询分类与部署诊断

**我的分析：** c 使用真标签 y；阈值又使用 batch 中已判对的样本。
没有真标签的新查询无法照搬这一流程。训练阶段利用 y 合法，不等于测试泄漏；
问题在于不能把训练分类流程直接包装成无标签线上诊断器。

此外，论文按初始精确集合内部的熵中位数再分组，会强制把其中至少约一半划到多义侧
（连续值且无并列时）。这种相对分组可以是有效的课程/软化策略，
却不能自动解释为“真实多义查询的比例约为一半”。
同一查询在不同 batch 中得到不同分类也是结构上可能的。

软标签可以缓和 false negatives，但模型认为相似不等于另一个视频真实相关。
缺少多正例判定时，它也可能保留错误的邻居。这是伪标签质量问题，
不能仅凭 ξ 的名字解决。

帧/片段意见来自同一视频且共享学习过程，Dempster–Shafer 聚合的收益
不等于两条意见提供了统计独立证据。对强相关意见的置信放大应单独讨论。

## 实验支持的结论范围

**我的判断：** 消融支持这套训练组合提高检索表现；移除 intra loss 的下降
说明稠密对齐是重要贡献。但当前不能拆解出“识别到真实歧义”的因果贡献，
因为类别由当前模型分数和标签共同构造，并且标签校准也是优化干预。

阅读主实验和附录，没有看到完整的 query-level failure AUROC/AURC、
风险阈值校准或三类语义标签的独立诊断基准。
所以引用时宜写“uncertainty-guided learning improves PRVR”，
不宜写“已经实现可部署、可靠的检索拒答”。

对我们当前课题，最值得保留的技术思想是让学习目标作用到排序所依赖的表示，
以及允许多个片段为查询提供支持。重新堆一个冻结的 standalone evidence head
不会自然获得同样的训练作用。
